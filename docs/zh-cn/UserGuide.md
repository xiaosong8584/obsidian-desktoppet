## 项目简介

**Desktop Pet for Obsidian** 是一个 Obsidian 社区插件，在你的笔记编辑器里放一只可爱的 **3D 卡通机器人**。

- 悬浮在 Obsidian 窗口任意位置，**完全透明背景**，不遮挡你的笔记内容
- **零外部资源依赖**：机器人由代码参数化生成（Sphere / Cylinder / Capsule / Torus 几何体组合），不需要下载任何图片或模型文件
- **完全开源**：MIT 许可证，自由修改、自由分发

### 设计理念

- **简约**：主色控制在 2 种以内，配合柔和色调，不喧宾夺主
- **不打扰**：外层容器 `pointer-events: none`，只有宠物本体可交互，其余区域鼠标穿透
- **不折腾**：即装即用，不需要手动配置模型、贴图、动画文件

## 获取与安装

### 方式一：从源码构建安装（推荐给想玩源码的用户）

如果你已经有 Node.js 环境，可以直接从 GitHub 拉源码构建：

```bash
# 1. 克隆仓库
git clone https://github.com/xiaosong8584/obsidian-desktoppet.git
cd desktoppet

# 2. 安装依赖并构建
npm install
npm run build

# 3. 复制产物到你的 Obsidian vault
#    （Windows 示例，其他系统按路径替换）
copy . C:\Users\你的用户名\AppData\Roaming\Obsidian\<你的vault>\.obsidian\plugins\desktoppet\
```

### 方式二：手动复制安装（最简单）

如果你已经拿到构建好的 `main.js` / `styles.css` / `manifest.json`：

1. **打开 Obsidian 设置** → 第三方插件 → **关闭安全模式**（Toggle 打开"社区插件"）
2. **打开你的 vault 目录**（设置 → 关于 → 当前 Vault 位置）
3. **创建插件目录**：
   ```
   <你的vault>/.obsidian/plugins/desktoppet/
     ├── main.js          # 必需（构建产物）
     ├── manifest.json    # 必需
     └── styles.css       # 必需
   ```
4. **重启 Obsidian**（或 设置 → 第三方插件 → 刷新）
5. **插件列表**搜索 "Desktop Pet"，点击启用

> **提示**：源码里的 `.ts` 文件不需要放到插件目录，只有构建产物（`.js`、`.json`、`.css`）是必需的。

### 方式三：通过社区插件浏览器安装（未来规划）

项目发布到 Obsidian 社区插件市场后，可以直接在 Obsidian 内安装。当前尚未上架，请使用方式一或方式二。

## 使用教程

### 启用插件

1. Obsidian 设置 → 第三方插件 → 找到 **Desktop Pet** → 打开开关
2. 插件启用后，窗口**左上角**会立即出现一个 3D 卡通机器人
3. 如果没看到，可能是"显示开关"默认关闭，去设置面板开启

### 拖动宠物

- **鼠标按住**宠物本体（不要按到空白处）
- **拖到任意位置**，松手后宠物会停在那儿
- 拖动过程中宠物会**微微倾斜**（跟随鼠标速度），松手后回正

> **小技巧**：拖动距离 < 5px 会被判定为"点击"而不是"拖动"。

### 点击宠物

- **单击**宠物本体，宠物会：
  1. **脉冲**一下（缩放 1.0 → 1.3 → 1.0，约 400ms）
  2. **眼睛变成弯月形**（开心表情）
  3. **头顶冒出气泡**，随机显示一句台词（10 句随机）

气泡 2.2 秒后自动消失。

### 切换显隐

三种方式任选：

1. **状态栏**：Obsidian 右下角有个小机器人图标，单击切换
2. **命令面板**：`Ctrl+Shift+P`（Mac: `Cmd+Shift+P`）→ 搜索 `Show/Hide Pet`
3. **设置面板**：设置 → 社区插件 → Desktop Pet → "启用"开关

### 调整宠物位置（不拖动）

设置面板 → Desktop Pet：

- **位置 X**：宠物左上角距窗口左边缘的像素值
- **位置 Y**：宠物左上角距窗口上边缘的像素值

默认 `(20, 20)`（左上角附近）。

## 设置项详解

进入 **设置 → 社区插件 → Desktop Pet**，你会看到：

### 基础开关

| 设置项    | 类型     | 说明                      |
| ------ | ------ | ----------------------- |
| **启用** | Toggle | 是否显示宠物。关闭后宠物完全隐藏，所有资源释放 |

### 外观

| 设置项      | 类型       | 范围          | 说明                          |
| -------- | -------- | ----------- | --------------------------- |
| **宠物大小** | Slider   | 0.5x ~ 2.0x | 宠物整体缩放倍率。默认 1.0x（180x180px） |
| **主色**   | Dropdown | 5 种预设       | 机器人主体颜色。眼睛、腮红、深色细节保持不变      |

**5 种预设主色**：

| 名称  | 颜色 | Hex       |
| --- | -- | --------- |
| 柔和蓝 | 🔵 | `#4A90D9` |
| 薄荷绿 | 🟢 | `#4ECDC4` |
| 珊瑚粉 | 🩷 | `#FF8A80` |
| 薰衣草 | 🟣 | `#A78BFA` |
| 暖橙  | 🟠 | `#F59E0B` |

### 位置

| 设置项      | 类型     | 说明                        |
| -------- | ------ | ------------------------- |
| **位置 X** | Number | 宠物左上角距窗口左边缘的像素值（0 ~ 屏幕宽度） |
| **位置 Y** | Number | 宠物左上角距窗口上边缘的像素值（0 ~ 屏幕高度） |

### 恢复默认

点击 **恢复默认设置** 按钮，所有设置回到初始值：

- 显示：启用
- 大小：1.0x
- 主色：柔和蓝
- 位置：(20, 20)

## 常见问题 FAQ

### Q1: 启用插件后没看到宠物？

**排查顺序**：

1. 设置面板 → Desktop Pet → **启用**开关是否打开？
2. 是不是在**全屏阅读模式**下？宠物在阅读器标签页可能不显示，切回编辑模式试试
3. 位置是不是设到了屏幕外？把位置 X / Y 都改成 `20` 试试
4. 打开 Obsidian 的开发者工具（`Ctrl+Shift+I`）看控制台有没有红色报错

### Q2: 宠物挡住了我的内容？

- **缩小**：设置面板 → 宠物大小 → 拖到 0.5x
- **挪位置**：直接拖动宠物到不挡内容的位置
- **隐藏**：状态栏图标或 `Ctrl+Shift+P` → `Show/Hide Pet`

### Q3: 宠物拖动的时候位置不准？

拖动过程中鼠标必须**保持按住**。如果松手后再点，会变成"点击"而不是"继续拖动"。拖动距离 < 5px 会被判定为点击。

### Q4: 气泡被窗口顶部裁切了？

气泡显示在宠物容器**顶部**。如果宠物位置 Y 太小（如 0），气泡会被裁切。把宠物位置 Y 调到 100 以上即可。

### Q5: 换主色后宠物没变？

主色替换采用"非白非深非腮红即为主色"启发式策略。当前模型没有额外辅助色，切换应该立即生效。如果没生效，可能是你改了宠物代码但没重新 build——重新跑 `npm run build`。

### Q6: 宠物在明暗主题切换后颜色怪怪？

明暗主题切换会影响：

- 气泡背景色（使用 `--background-primary` CSS 变量）
- 阴影颜色（使用 `--background-modifier-border`）
- 宠物本体颜色**不会**随主题变化（由主色控制）

如果换主题后宠物本体看起来"突兀"，可以换一种更中性的主色（如柔和蓝、薰衣草）。

### Q7: 插件和某些主题冲突？

宠物使用**独立 DOM 层**（挂到 `document.body`），不受主题 CSS 影响。如果确实冲突，可以尝试：

1. 关闭自定义主题
2. 检查是否有其他插件修改了 `body` 的 z-index
3. 提交 Issue 并附上复现步骤

### Q8: 我可以让宠物显示别的角色吗？

当前只有一种机器人形象（参数化几何体组合）。**后续可扩展方向**包含多种机器人外形（球型 / 方块型 / 拟人型）。如果你想改代码：

- 修改 `pet/PetModel.ts` 里的 `createPetModel()` 函数
- 保持 `PetModelParts` 接口不变（需要暴露 `group`、`eyes`、`mouth`、`armL`、`armR`、`antenna`）
- 重新 `npm run build`

### Q9: 我可以让宠物显示自定义台词吗？

可以。台词硬编码在 `pet/PetInteraction.ts` 的 `PHRASES` 数组里：

```typescript
const PHRASES = [
  '你好~',
  '嗨!',
  '想我了吗？',
  '今天也要加油鸭~',
  '在吗？',
  '摸鱼中...',
  '该休息啦~',
  '继续加油!',
  '我在这儿~',
  '有事叫我嘛'
];
```

直接编辑这个数组，添加你的台词，重新 build 即可。

### Q10: 为什么我的宠物不眨眼了？

眨眼是随机的，2.5~6 秒一次。如果一直不眨，检查：

1. Obsidian 是否在前台（后台时 rAF 循环会暂停）
2. 浏览器开发者工具 Performance 面板是否显示动画还在跑
3. 提交 Issue 附上复现步骤

## 故障排查

### 方法一：查看插件控制台输出

1. Obsidian → 设置 → 开发者 → 打开开发者工具（`Ctrl+Shift+I`）
2. 切到 **Console** 标签
3. 启用 / 禁用插件，观察是否有红色报错
4. 把报错信息复制到 Issue 里反馈

### 方法二：检查插件状态

1. 设置 → 社区插件 → Desktop Pet
2. 如果**灰掉不能启用**：manifest.json 可能损坏，重新复制插件目录
3. 如果**启用后闪退**：main.js 版本不匹配，重新跑 `npm run build`
4. 如果**启用后没反应**：查看 Console 输出

### 方法三：重置插件数据

插件把设置存在 Obsidian 的 `data.json`：

```
<你的vault>/.obsidian/plugins/desktoppet/data.json
```

删除这个文件，重启 Obsidian，插件会回到默认设置。

### 方法四：完全卸载

1. Obsidian 设置 → 社区插件 → 关闭 Desktop Pet
2. 删除 `<你的vault>/.obsidian/plugins/desktoppet/` 目录
3. 重启 Obsidian
